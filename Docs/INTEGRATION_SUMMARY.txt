🎉 WHAT'S NEW IN v2.1

The Neural AI Loader now includes a fully integrated documentation viewer
with smart navigation, automatic document discovery, and intelligent
categorization - all accessible from the main menu!


📋 KEY FEATURES

✅ Integrated Help Menu
   • Access all documentation directly from main menu
   • Option 2: "Documentation & Help"
   • No need to open separate files

✅ Smart Document Scanning
   • Automatically discovers all .md and .txt files in root\docs\
   • Shows available file count in main menu
   • Example: "2) Documentation & Help (5 files)"

✅ Intelligent Categorization
   • Documents auto-organized by type:
     - Getting Started (README, QUICK_START, etc.)
     - Guides (GUIDE_*, HOW, MANUAL, etc.)
     - Reference (IMPLEMENTATION, REFERENCE, etc.)
     - Troubleshooting (TROUBLESHOOTING, DEBUG, ERROR, etc.)
     - Other (miscellaneous files)

✅ Interactive Navigation
   • Page through long documents (N for next, P for previous)
   • Return to menu (B) from anywhere
   • Quit program (Q) from anywhere
   • Return to main menu at any point (M option on selections)

✅ Full Integration
   • Logging of all doc viewer activity
   • Debug mode support
   • Graceful error handling
   • Consistent with existing UI


🏗️ ARCHITECTURE

New File: doc_viewer.py (230 lines)
  - scan_documents() - Find all docs in root\docs\
  - categorize_documents() - Auto-sort by type
  - show_doc_viewer() - Main viewer entry point
  - show_doc_menu() - Document selection menu
  - show_document() - Document reader with paging
  - paginate_text() - Split documents into pages

Updated File: neural_ai_loader.py (550+ lines)
  - New "HOME" state in NavState
  - Main menu with 3 options (Start/Help/Quit)
  - Integration of doc_viewer calls
  - Full navigation support with back/home options
  - State machine for menu flow
