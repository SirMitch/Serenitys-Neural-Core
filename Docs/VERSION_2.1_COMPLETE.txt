🏗️ ARCHITECTURE

Core State Machine:
  HOME ──→ 1) AI SESSION FLOW (existing)
        ├─→ 2) DOCS VIEWER (new)
        │     ├─ Scan docs/
        │     ├─ Categorize
        │     ├─ Show menu
        │     ├─ Read document
        │     └─ Return to HOME
        └──→ 3) QUIT

  doc_viewer.py:
    ├─ get_documentation_summary() - Used in HOME menu

neural_ai_loader.py:
    ├─ New HOME state
